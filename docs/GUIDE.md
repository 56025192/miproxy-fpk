# 控制面板使用指南

## 访问控制面板

### 默认地址

| 地址 | 说明 |
|------|------|
| `http://NAS_IP:9090` | 局域网访问 |
| `http://localhost:9090` | 本机访问 |

> 💡 NAS_IP 为你的飞牛 NAS 的局域网 IP 地址

### 访问要求

- 设置了面板密钥？首次访问需要输入密钥
- 未设置密钥？直接访问即可

## 基础操作

### 选择代理节点

**方法一：点击选择**
1. 在节点列表中点击目标节点
2. 等待切换完成（1-3秒）
3. 确认当前节点已更新

**方法二：延迟测试后选择**
1. 点击「延迟测试」或「测试延迟」
2. 系统自动测试所有节点延迟
3. 选择延迟最低的节点

### 测试节点延迟

**Zashboard：**
1. 点击右上角「延迟测试」按钮
2. 等待测试完成
3. 按延迟排序选择节点

**MetaCubeXD：**
1. 点击「测试延迟」按钮
2. 查看各节点延迟数据
3. 选择合适的节点

### 查看流量统计

| 指标 | 说明 |
|------|------|
| 上传 | 本机通过代理上传的数据量 |
| 下载 | 本机通过代理下载的数据量 |
| 当前速度 | 实时传输速率 |

## 订阅管理

### 添加订阅

1. 进入「订阅管理」或「配置」页面
2. 选择订阅类型：
   - **远程订阅 URL**：输入订阅链接
   - **本地订阅文件**：输入配置文件路径
3. 设置自动刷新间隔
4. 保存配置

### 手动刷新订阅

1. 点击「刷新」或「更新订阅」按钮
2. 等待刷新完成
3. 检查节点列表是否更新

### 自动刷新

| 间隔 | 适用场景 |
|------|----------|
| 1 小时 | 节点频繁更换 |
| 6 小时 | 一般使用（推荐） |
| 12 小时 | 低频更新 |
| 关闭 | 仅手动刷新 |

## 规则配置

### 常用规则类型

| 规则类型 | 说明 | 示例 |
|----------|------|------|
| DOMAIN | 精确域名匹配 | `DOMAIN,google.com` |
| DOMAIN-SUFFIX | 域名后缀匹配 | `DOMAIN-SUFFIX,google.com` |
| DOMAIN-KEYWORD | 域名关键词 | `DOMAIN-KEYWORD,google` |
| GEOIP | IP 地理位置 | `GEOIP,CN` |
| RULE-SET | 规则集 | `RULE-SET,geosite,Proxy` |
| MATCH | 默认规则 | `MATCH,Proxy` |

### 推荐的规则顺序

\`\`\`
# 1. 本地服务直连
DOMAIN-SUFFIX,local
DOMAIN-SUFFIX,lan

# 2. 国内网站直连
GEOIP,CN
RULE-SET,geosite@category-lib-cn,Direct

# 3. 广告拦截
RULE-SET,advertisement,Reject

# 4. 代理流量
RULE-SET,geosite,Proxy

# 5. 默认规则
MATCH,Proxy
\`\`\`

### 常用规则集

| 规则集 | 用途 |
|--------|------|
| `geosite@category-lib-cn` | 国内常用网站 |
| `geosite@google` | Google 全家桶 |
| `geosite@github` | GitHub |
| `geosite@twitter` | Twitter/X |
| `geosite@youtube` | YouTube |
| `geosite@netflix` | Netflix |

## 代理设置

### 浏览器代理配置

**Chrome / Edge：**
1. 安装 SwitchyOmega 插件
2. 新建代理配置：
   - 代理协议：SOCKS5
   - 服务器：NAS_IP
   - 端口：7891
3. 启用代理配置

**Firefox：**
1. 设置 → 常规 → 网络设置
2. 手动代理配置：
   - SOCKS 主机：NAS_IP
   - 端口：7891
   - SOCKS v5：✓

### 系统代理配置

**Windows：**
设置 → 网络和 Internet → 代理 → 手动代理设置

**macOS：**
系统偏好设置 → 网络 → 高级 → 代理

**Linux：**
系统设置 → 网络 → 网络代理

### 代理协议说明

| 协议 | 端口 | 用途 |
|------|------|------|
| HTTP | 7890 | 浏览器 HTTP/HTTPS 流量 |
| SOCKS5 | 7891 | 支持 UDP 的应用 |
| Mixed | 7890 | 混合代理 |

## 进阶功能

### TUN 模式（全局代理）

**说明：** 将系统所有流量通过代理转发

**启用条件：**
- 需要内核支持
- fnOS 环境可能不可用

**风险：**
- 可能影响系统稳定性
- 部分服务可能异常

**建议：** 普通代理模式已能满足大多数需求

### DNS 配置

推荐配置：
\`\`\`yaml
dns:
  enable: true
  listen: 0.0.0.0:53
  enhanced-mode: fake-ip
  fake-ip-range: 198.18.0.1/16
  nameserver:
    - 223.5.5.5
    - 119.29.29.29
  fallback:
    - 8.8.8.8
    - 1.1.1.1
\`\`\`

### 代理链（Proxy Chain）

用于多层代理：
\`\`\`yaml
proxies:
  - name: "香港节点"
    type: vmess
    # ...

  - name: "美国节点"
    type: trojan
    # ...

proxy-groups:
  - name: "代理链"
    type: select
    proxies:
      - 香港节点
      - 美国节点
    # 使用 relay 实现代理链
    relay: 香港节点
\`\`\`

## 安全建议

### 1. 设置面板密钥

- 安装时务必设置面板密钥
- 定期更换密钥
- 不要使用简单密码

### 2. 限制访问

- 仅在局域网内访问控制面板
- 如需外网访问，使用 VPN 或设置强密码

### 3. 定期更新

- 关注 [Releases](https://github.com/56025192/miproxy-fpk/releases) 更新
- 及时更新版本修复安全问题

### 4. 备份配置

\`\`\`bash
# 备份配置
cp -r /vol1/@appdata/miproxy /vol1/@appshare/miproxy_backup_$(date +%Y%m%d)
\`\`\`
